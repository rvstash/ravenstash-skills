# Security policy

Agent skills are executable supply-chain inputs: they can influence commands, credential handling, and remote changes. Treat instruction injection, credential disclosure, unsafe command construction, unauthorized mutations, and compromised bundled resources as security issues.

Report a vulnerability through this repository's private GitHub Security Advisory flow. Do not put credentials, exploit details, private Ravenstash hosts, or customer information in a public issue or pull request.

For a suspected exposed Ravenstash credential, revoke or rotate it immediately through the owning account before waiting for repository triage.
